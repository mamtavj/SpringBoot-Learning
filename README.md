# Spring Boot Learning 🚀

This repository contains my journey of learning **Java Backend Development with Spring Boot**.

## 📚 Topics Covered

### 1. Maven & Project Management

* Maven and Maven project structure
* Maven lifecycle
* Dependencies
* `pom.xml`

### 2. Dependency Injection

* What is Dependency Injection?
* Why Dependency Injection is used
* How Spring injects dependencies into objects

### 3. IoC, Beans & Bean Initialization

* Inversion of Control (IoC)
* Spring Container
* Spring Beans
* `@Configuration`
* `@Bean`
* Different ways of Bean initialization

### 4. Circular Dependency & Bean Scope

* Circular Dependency between Beans
* Singleton and Prototype Bean Scopes
* How Bean Scope can help resolve Circular Dependency

### 5. Bean Lifecycle

* Complete Spring Bean Lifecycle
* Bean initialization and destruction phases
* Lifecycle callbacks
* `@PostConstruct`
* `@PreDestroy`
* `destroyMethod`

### 6. Spring Boot Configuration & Auto-Configuration

* Understood `@SpringBootApplication` and its three main annotations:

  * `@SpringBootConfiguration`
  * `@EnableAutoConfiguration`
  * `@ComponentScan`
* Learned how `SpringApplication.run()` starts the application and creates the `ApplicationContext`.
* Understood how Spring Boot automatically configures required components based on project dependencies.
* Learned about `spring-boot-starter-parent` and Maven dependency management.

### 7. Application Properties

* Learned the purpose of application.properties in configuring a Spring Boot application.
* Used @Value to inject individual property values, including default values.
* Learned @ConfigurationProperties to bind a group of related properties to a Java class using a common prefix.
* Understood how Spring injects configuration properties into beans using constructor injection.
* Learned about ApplicationRunner and how it executes code after Spring Boot application startup.

## 🛠️ Tech Stack

* Java
* Spring Framework
* Spring Boot
* Maven
* IntelliJ IDEA

## 🎯 Goal

To build a strong foundation in **Spring Boot and Java backend development** through hands-on learning and projects.
